## 1. Активация плагина

1. Откройте **Obsidian**.
2. Если плагин только что скопирован/обновлен, нажмите **`Ctrl + R`** для перезагрузки интерфейса.
3. Перейдите в **Settings** (шестеренка слева внизу) → **Community plugins**.
4. Убедитесь, что плагин **Canvas Code Links** включен (тумблер активен).

---

## 2. Как работают относительные пути (Relative Paths)

Главная сила плагина — **переносимость**. Вы не привязываетесь к диску `C:\` или имени пользователя Windows. Репозиторий можно клонировать на любой компьютер, и все ссылки останутся рабочими.

### Пример вашей структуры:
```text
GamePC/                              <-- Корень репозитория / Хранилища
├── Assets/
│   └── Scripts/
│       └── Player/
│           └── PlayerController.cs  <-- Исходный код (строка 42)
└── docs/
    └── game.canvas                  <-- Ваш канвас
```

### Как считается путь:
Файл `game.canvas` лежит внутри папки `docs/`. Чтобы добраться до `Assets/`:
1. Поднимаемся на 1 папку выше: `../` (мы оказались в `GamePC/`).
2. Заходим в `Assets/Scripts/Player/PlayerController.cs`.
3. Добавляем номер строки: `:42`.

**Итоговый путь:**
`../Assets/Scripts/Player/PlayerController.cs:42`

> 💡 **Fallback от корня**: Если вам удобнее писать путь от корня репозитория (без `../`), пишите `Assets/Scripts/Player/PlayerController.cs:42`. Плагин автоматически проверит корень репозитория!

## 3. Способ 1: Создание карточки вручную

1. Откройте ваш файл `.canvas` (например, `game.canvas`).
2. Дважды кликните по пустому месту на канвасе (создастся текстовая карточка) или перетащите значок карточки из панели инструментов.
3. Введите текст карточки. Ссылку на код оформляйте в формате `[Текст ссылки](относительный_путь:строка)`:

```markdown
### 🎮 Игрок и Управление

Основная логика прыжка и перемещения:
[PlayerController.cs:42](../Assets/Scripts/Player/PlayerController.cs:42)
```

4. Кликните мимо карточки, чтобы выйти из режима редактирования.
5. **Результат**: ссылка превратится в аккуратный фиолетовый бейдж `{ } PlayerController.cs:42`.
6. Нажмите на бейдж — файл откроется в VS Code ровно на строке 42!

> ⚠️ **Важно**: Клик по *самой карточке* (в пустое место или заголовок) просто выделяет карточку. Для перехода в VS Code нажимайте именно на сам бейдж.

## 4. Способ 2: Быстрая вставка через команду (рекомендуется)

Плагин содержит интерактивное диалоговое окно, которое само рассчитывает относительные пути и проверяет существование файла.

1. Находясь в `.canvas`, нажмите **`Ctrl + P`** (палитра команд).
2. Наберите **`Insert Code Link Card`** и нажмите **Enter**.
3. В открывшемся окне:
   - **File Path**: введите путь к файлу. 
     *Можно просто скопировать абсолютный путь из проводника Windows или VS Code (например `C:\...\PlayerController.cs`), плагин автоматически вычислит `../Assets/...` относительно текущего канваса!*
   - **Line Number**: укажите строку (например `42`).
   - Внизу в блоке **Output Preview** появится зеленая галочка:  
     `✓ Exists on disk: C:\...\PlayerController.cs` (подтверждает, что путь указан верно).
4. Выберите стиль карточки:
   - `Markdown Link` — компактная ссылка `[file:42](./path:42)`.
   - `Rich Code Card` — карточка с заголовком и кнопкой перехода.
5. Нажмите **Insert into Canvas / Note** — карточка мгновенно добавится в центр канваса!

## 5. Таблица форматов ссылок

Вы можете использовать любой привычный синтаксис:

| Формат | Пример синтаксиса | Поведение |
|---|---|---|
| **Двоеточие + строка** | `[PlayerController.cs:42](../Assets/.../PlayerController.cs:42)` | Открывает строку 42 |
| **Строка и колонка** | `[Player.cs:42:10](../Assets/.../Player.cs:42:10)` | Строка 42, символ 10 |
| **GitHub Style `#L`** | `[PlayerController.cs](../Assets/.../PlayerController.cs#L42)` | Открывает строку 42 |
| **Явный префикс `code:`** | `[Логика](code:../Assets/.../PlayerController.cs:42)` | Гарантированное открытие в редакторе |
| **Вики-ссылка** | `[[../Assets/.../PlayerController.cs:42]]` | Внутренний формат Obsidian |

## 6. Быстрый рабочий процесс из VS Code

Самый быстрый способ добавлять ссылки при разработке:

1. В **VS Code** откройте нужный скрипт (например, `PlayerController.cs`).
2. Посмотрите номер строки (например, строка `68` у метода `TakeDamage()`).
3. Кликните правой кнопкой на вкладку файла или в проводнике VS Code → **Copy Relative Path** (или `Shift + Alt + C`).
4. В **Obsidian Canvas** нажмите горячую клавишу вставки (см. пункт 7) → вставьте путь → укажите строку `68` → **Enter**.
5. Готово! Карточка на канвасе связана со строкой метода.

---

## 7. Настройка горячих клавиш

Чтобы открывать окно вставки одной комбинацией клавиш:

1. В Obsidian: **Settings** → **Hotkeys** (Горячие клавиши).
2. В строке поиска введите: `Canvas Code Links: Insert Code Link Card`.
3. Нажмите на значок плюса и задайте удобную комбинацию (например, **`Alt + C`** или **`Ctrl + Shift + K`**).
4. Теперь создавать карточки с кодом можно за 2 секунды!

## 8. Смена редактора (Cursor, Rider, Obsidian)

Если вы работаете в другом редакторе:

1. Откройте **Settings** → вкладка **Canvas Code Links** (слева в списке плагинов).
2. В пункте **Default Code Editor** выберите:
   - **Visual Studio Code** (`vscode://`)
   - **Cursor** (`cursor://`)
   - **JetBrains Rider** (`jetbrains://rider/`)
   - **Obsidian Internal Editor** (открывать прямо в Obsidian)
   - **Custom CLI Command** (например `code -g "{path}:{line}"`)
